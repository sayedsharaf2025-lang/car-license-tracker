# 🚛 نظام إدارة الأسطول — شركة البنا جروب
### EL BANNA GROUP — Fleet Management System

نظام ويب متكامل لإدارة أسطول السيارات يشمل: المخالفات، التراخيص، المشرفين، الفواتير، والمصروفات العامة. يعمل بالكامل عبر المتصفح مع مزامنة فورية عبر Firebase Realtime Database.

---

## ✨ المزايا الرئيسية

| الميزة | التفاصيل |
|--------|----------|
| 🔐 نظام صلاحيات | 5 أدوار: أدمن، مشرف، مدير حركة، مدير مالي، مشرف عام |
| 🚗 إدارة السيارات | إضافة وتعديل وحذف + بحث متقدم |
| 🪪 تتبع التراخيص | تنبيهات انتهاء التراخيص (30 يوم / منتهية) |
| ⚠️ المخالفات | تسجيل مخالفات وخصومات السائقين |
| 📄 سير الفواتير | إنشاء ← اعتماد ← طباعة وخصم عهدة |
| 🧾 المصروفات العامة | نقدي وفيزا + تحميل على سيارات |
| 📊 تقارير شاملة | مخالفات، سائقين، تراخيص، فواتير، كشف حساب |
| 🖨️ طباعة فواتير | تنسيق A5 احترافي جاهز للطباعة |
| 📥 استيراد/تصدير | CSV + Excel + JSON backup |
| 🔄 مزامنة فورية | Firebase Realtime Database |
| ⏱️ خروج تلقائي | بعد 30 دقيقة من الخمول |

## 🚀 البدء السريع

### 1. تحميل المشروع
```bash
git clone https://github.com/YOUR_USERNAME/el-banna-fleet.git
cd el-banna-fleet
```

### 2. فتح النظام
افتح ملف `index.html` مباشرة في المتصفح أو استخدم Live Server في VS Code.

```
index.html  ← افتح هذا الملف
```

> **ملاحظة:** لتجنب مشاكل CORS عند استيراد ملفات، يُفضل استخدام VS Code Live Server أو أي خادم محلي بسيط.

### 3. بيانات الدخول الافتراضية

| المستخدم | الباسورد الافتراضي | الدور |
|----------|-------------------|-------|
| `admin` | `1234` | مدير النظام الكامل |
| `traffic` | `5678` | مدير الحركة |
| `finance` | `9999` | المدير المالي |
| `manager` | `0000` | المشرف العام |

> ⚠️ **غيّر كلمات المرور الافتراضية** من قسم "كلمات المرور" بعد أول تسجيل دخول.

## ☁️ إعداد Firebase

### إذا أردت استخدام قاعدة بياناتك الخاصة:

1. افتح [Firebase Console](https://console.firebase.google.com)
2. أنشئ مشروعاً جديداً
3. فعّل **Realtime Database** (ابدأ في وضع الاختبار)
4. افتح `app.js` وعدّل `firebaseConfig` في أعلى الملف:

```javascript
const firebaseConfig = {
  apiKey:            "YOUR_API_KEY",
  authDomain:        "YOUR_PROJECT.firebaseapp.com",
  databaseURL:       "https://YOUR_PROJECT-default-rtdb.firebaseio.com",
  projectId:         "YOUR_PROJECT",
  storageBucket:     "YOUR_PROJECT.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId:             "YOUR_APP_ID"
};
```

5. أضف قواعد الأمان في Firebase Console:
```json
{
  "rules": {
    ".read":  "auth != null",
    ".write": "auth != null"
  }
}
```

> للتطوير المحلي فقط، يمكن استخدام:
> ```json
> { "rules": { ".read": true, ".write": true } }
> ```
